### ❤️ Heart Disease Prediction

A Machine Learning application for predicting potential heart disease risk based on clinical patient data.

**Dataset:**

- UCI Heart Disease Dataset
- 303 records
- 13 features

Different Machine Learning models were evaluated, with Logistic Regression selected as the final model.

**Performance:**

- Accuracy: 88.89%
- Precision: 89%
- Recall: 89%
- F1-Score: 89%

[Live Demo](https://heart-disease-prediction-33vt.vercel.app/)
