PROJECT 01 — AI / COMPUTER VISION

Brain Tumor MRI Segmentation

A deep learning computer vision project designed to segment brain tumor regions from MRI images.

Project Overview

The project focuses on medical image segmentation using a deep learning model. The objective is to receive an MRI image and produce a segmentation mask that identifies the tumor region.

Dataset

LGG MRI Segmentation Dataset 3,929 MRI Images 3,929 Corresponding Masks 3,143 Training Images 393 Validation Images 393 Test Images

Preprocessing

  • MRI images are resized to 256 × 256.
  • ImageNet normalization is applied.
  • The same preprocessing approach is used during training and inference.

Model Architecture

U-Net++

U-Net++ Segmentation

Encoder

ResNet50 Deep Learning

Framework

PyTorch

Prediction Workflow

  1. Receive the MRI image
  2. Preprocess the image
  3. Resize to 256 × 256
  4. Apply ImageNet normalization
  5. Run U-Net++ with ResNet50
  6. Apply Sigmoid activation
  7. Apply a threshold of 0.5
  8. Resize the predicted mask to the original dimensions
  9. Create a visual overlay

Technologies

Python PyTorch U-Net++ ResNet50 Deep Learning Computer Vision Image Segmentation

My Contribution

The project combines dataset preparation, image preprocessing, model development, segmentation workflow and deployment-oriented thinking into one practical computer vision system.

What I Learned

  • Working with medical image segmentation.
  • Understanding the complete preprocessing and inference pipeline.
  • Connecting a deep learning model to a practical application.

Educational and engineering project. It is not intended to provide medical diagnosis.

PROJECT 04 — EMBEDDED / AUTOMATION

CNC Pen Plotter

An Arduino-based CNC system designed to convert digital drawing paths into physical pen movement.

Project Concept

The system receives a digital drawing or path and translates it into movement commands. The Arduino and GRBL handle motion control while the servo controls the pen position.

Main Components

Arduino

Main controller responsible for receiving and processing the control commands.

CNC Shield

Interface for connecting and controlling the motion components.

GRBL

Motion-control firmware used to interpret CNC movement commands.

Stepper Motors

Provide controlled movement for the CNC axes.

Servo

Controls the pen up and down movement.

System Workflow

Digital Drawing Movement Commands Arduino / GRBL Stepper Axes Pen Control

Pen States

Pen Down

The pen touches the drawing surface while the machine moves through the drawing path.

Pen Up

The pen is lifted while the machine moves between separate drawing sections.

Technologies

Arduino CNC Shield GRBL Stepper Motors Servo G-Code

Engineering Perspective

The project brings together programming, electronics, motion control and mechanical movement into one integrated system.

What I Learned

  • Understanding CNC motion control.
  • Working with Arduino and GRBL.
  • Connecting software commands with physical movement.

PROJECT 05 — ROBOTICS / EMBEDDED

Line Following Robot

An autonomous robot that reads a path using IR sensors and continuously adjusts its movement through motor-control logic.

Project Concept

The robot is designed to follow a predefined path automatically. It uses sensor readings to determine the required direction and then adjusts the motors accordingly.

Main Components

Microcontroller / Arduino

Processes sensor readings and controls the robot's behavior.

IR Sensors

Detect the path and provide feedback to the controller.

DC Motors

Provide the physical movement of the robot.

Motor Driver

Interfaces between the controller and the motors.

Chassis & Wheels

Provide the physical structure and movement platform.

Control Loop

Sensor Reading Decision Motor Control Movement New Sensor Reading

Movement Logic

  • When the center detects the path, the robot moves forward.
  • When the path shifts to the right, the robot corrects toward the right.
  • When the path shifts to the left, the robot corrects toward the left.
  • If the path is lost, the control logic attempts to recover the direction.

PWM Speed Control

PWM can be used to control motor speed, allowing the robot to adjust its movement according to the required correction.

Improving Movement

Movement can be improved by balancing motor speeds and making the correction behavior more controlled, especially during turns.

Testing

Straight Lines Simple Curves Sharp Turns Direction Changes Difficult Detection Sections

Challenges

Sensor Calibration

Making sure the sensor readings are reliable enough for movement decisions.

Motor Differences

Different motor behavior can affect straight movement and corrections.

Sharp Turns

Sharp turns require fast and accurate correction.

Speed

Higher speed can make the robot harder to control during corrections.

Possible Improvements

  • Using more sensors for more detailed path detection.
  • Applying PID control for smoother and more accurate corrections.
  • Improving the relationship between speed and correction.

Engineering Perspective

Programming

Writing the control logic and decision behavior.

Electronics

Connecting sensors, controller and motors.

Embedded Systems

Combining software logic with hardware behavior.

Robotics

Building an autonomous physical system.

Control Systems

Using feedback to continuously adjust the robot's movement.

What I Learned

The project strengthened my understanding of the relationship between sensors, programming, electronics, motor control and autonomous behavior.

My Contribution

The project combines programming, sensor-based feedback, motor control and robotics concepts into one practical autonomous system.

Conclusion

The Line Following Robot is a practical example of how sensing, decision-making and physical control can work together to create autonomous behavior.
